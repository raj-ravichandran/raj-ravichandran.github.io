    Systems

    • Scale

      Keeping metrics live for thousands of clients

      Sending every metric as it happens would flood the network and memory. Batching and compression cut message volume and Redis footprint, so charts stay sub-second while the system serves thousands of sessions.

      • Batching
      • Compression
      • Memory optimization
    • Data model

      Time series on Redis structures

      Sorted sets keep samples ordered by time for fast range reads, hashes and lists hold session state, and pub/sub and streams carry events. Threshold checks and fault-tolerant backup sit on the same model, and caching in front of the database reduces its load.

      • Sorted sets
      • Pub/Sub
      • Streams
      • Event queue
    • Reliability

      Failing safely on a 24x7 service

      Sessions can drop at any point, so the gateway detects faults, balances load, and ends sessions reliably to avoid stuck state. Retry and recovery paths back it up, and I treat production incidents as design feedback.

      • Fault detection
      • Retries
      • Recovery
      • Incident response
